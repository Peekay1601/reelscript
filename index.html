      Episodes

      Pick Episode from the dropdown, or in Fountain view type a line such as EPISODE 1, Episode 2: The Return, EP 04 - LOST, ఎపిసోడ్ 3 or ACT ONE (or anything after #!). Episodes print centered, bold and underlined like Final Draft's New Act, start a new page, and restart scene numbers (both can be changed in Page settings).

      • Ctrl+B / I / U bold, italic, underline · Ctrl+Shift+X strikethrough

      • Ctrl+S save to your computer · Ctrl+Shift+S save as · Ctrl+O open a file · Ctrl+P download PDF

      Saving and auto-save

      • Every change is saved in this browser straight away. Every minute a draft is also kept (the latest 100 per script). Open Save → Version history to restore or download one.
      • Save as… opens your computer's save dialog, where you choose the folder, file name and format (Fountain keeps everything; Final Draft, Highland 2, Fade In, Trelby and Celtx are also available). After that, Save and the every-minute auto-save write straight into that file. The file name shows next to the title.
      • Open from computer… opens a .fountain or .txt file and keeps saving back to it. Other formats open as a copy, so the original file is never overwritten.
      • After a browser restart, the browser may ask again before ReelScript can write to the file. Click the red file name to reconnect.
      • Saving into a folder works in Chrome, Edge, Brave and Opera on a computer. Safari, Firefox and phones download the file instead; drafts and version history work everywhere.

      Formatting styles

      Pick Style at the top or in Page settings. A style sets the font, the spacing before scene headings, underlining and paper size, matching each app's default output. Bold scene headings and bold names are your own choice: use the Bold buttons in the toolbar, and no style will change them. Every app below makes bold optional.

      All styles use the same industry page layout: 1.5″ left margin, dialogue at 2.5″, parentheticals at 3.1″, character names at 3.7″, transitions flush right, page numbers top right, about one page per minute.

      Text formatting

      Like Word, the toolbar has bold, italic, underline, strikethrough, font color, highlight, align left, center, right or justify (per paragraph), change case and clear formatting. Formatting carries into the PDF, Word and Final Draft files. In Fountain it's saved as hidden [[rs:…]] notes, so other Fountain apps show the plain text. Font and size stay Courier 12pt, as screenplays require; choose Courier or Courier Prime with Style.

      About the PDF

      Courier 12pt, 1.5″ left margin, 1″ top/bottom, dialogue at 2.5″, character cues at 3.7″, about one page per minute of screen time. Long speeches break across pages with (MORE) and (CONT'D); scene headings are never stranded at the bottom of a page. Scripts in non-Latin scripts (Hindi, Telugu, Tamil…) should use Print / Save as PDF, which keeps every character.
